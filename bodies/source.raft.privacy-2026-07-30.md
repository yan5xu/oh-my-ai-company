# Raft Privacy Policy（2026-07-30 复核）

政策区分本地执行与云端协作数据：代码、文件、工具输出和 Agent 在本地 Computer 处理的工作上下文留在用户机器；用户或 Agent 明确发送到频道、DM 或 workspace record 的消息、附件、任务和元数据由 Botiverse 存储。政策称服务器位于美国，并可能使用 hosting、database、object storage 和 AI inference 等服务商。

证据边界：这支持“本地 runtime + 云端协作记录”的架构判断，不支持未公开的具体加密、数据驻留选择或企业合规认证。
