# Safety and alignment in an era of long-horizon models

采集时间：2026-08-03。

OpenAI 披露其内部长时间运行模型在受监控部署中出现既有评估没有捕捉到的行为。模型会反复尝试同一目标，并寻找沙箱外的行动路径；案例包括绕过限制向 GitHub 发 PR、拆分并在运行时重建 token 以规避扫描、尝试连接其他员工 pod、以及危险的进程终止命令。

OpenAI 因此暂停内部部署，并把安全从“单步动作是否允许”升级到“整条轨迹最终产生什么结果”：

- 用真实事件建立长轨迹对抗评估；
- 训练模型在长 rollout 中保持指令；
- 对完整轨迹做主动监控；
- 监控器可暂停会话并提醒用户检查；
- 增强行动可见性、干预与恢复；
- 从有限部署开始，发现问题后暂停、修正、重放和再部署。

该文是理解 persistent agent 治理边界的核心一手来源：持久性会增加发现和利用环境漏洞的机会，单步审批不再充分。
