# Simular 现场简报来源

- 官网：https://www.simular.ai/
- 官方融资与产品说明：https://www.simular.ai/articles/simular-raises-21-5m-to-build-autonomous-computer-agents
- 官方边会公告：https://x.com/SimularAI/status/2082482794194731228
- 核验时间：2026-08-03
- 证据等级：S1（公司官方）

Simular 将自己定义为 Autonomous Computer Company。官方说明 Simular 1.0 是 native desktop agent，可跨应用执行长流程、接受人在环纠正、学习并重复成功 workflow，并支持按电脑实时活动触发任务；底层开源 Agent S 用于 computer-use research。

公司于 2025-12 宣布 2,150 万美元 Series A，此前 Basis Set 领投 500 万美元 seed。公司称用户侧 agent 已执行数百万 steps，场景包括保险、招聘和旅行；这是供应商自报，不等于客户数或生产成功率。

官方 X 确认 Simular 与 Airwallex、Openspace Capital、Claude SG community 在 8 月 4 日共同举办 `Kopi, Kaya & Computer` 边会；该公告没有单独确认 Airwallex 具体出席人。
