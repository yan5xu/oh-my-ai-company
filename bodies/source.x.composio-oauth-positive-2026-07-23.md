# X user feedback: Composio authorization convenience

Published: 2026-07-23; collected: 2026-07-29.

URLs:

- <https://x.com/tonysimons_/status/2080093855618093364>
- <https://x.com/tonysimons_/status/2080135417693720800>

Tony Simons said Composio let a Hermes setup connect Gmail, Canva, Google
Analytics, Gumroad, and Cloudflare with much less API-key/manual integration
work. In a follow-up, he clarified that each app is still separately
authorized and revocable, while the default managed setup uses default scopes;
least-privilege deployments should use custom sessions/MCP with explicit apps,
scopes, and actions.

This is a named user claim on X, potentially influenced by creator or
promotional incentives. It is S3 evidence for perceived setup value and the
need for explicit least-privilege configuration.
