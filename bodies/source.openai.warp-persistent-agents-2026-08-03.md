# Warp’s big bet on building open source with GPT-5.5

采集时间：2026-08-03。这是 OpenAI 发布的 Warp 客户案例，产品与经营数字主要来自 Warp 自述。

案例把软件开发描述为从人与单个 coding assistant 交互，演进为“跨时间协调大量 persistent agents”。Warp 的 Oz 作为本地/云端 control plane，支持后台远程 Agent、状态监控、代码审阅、周期性工作流、云端与本地迁移，以及上下文压缩、持久记忆和专用 subagents。

文章列出的系统条件与 OpenAI Frontier/Ona 方向一致：共享内存、可复现环境、评估、权限、协作、可观测性与人工审查。它证明 OpenAI 正用模型支持生态伙伴的 persistent-agent orchestration，但不证明 Oz 是 OpenAI 自有产品。
