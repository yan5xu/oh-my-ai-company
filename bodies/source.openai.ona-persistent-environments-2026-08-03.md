# OpenAI to acquire Ona

采集时间：2026-08-03。OpenAI 宣布计划收购 Ona，交易仍需满足交割与监管条件；在完成前两家公司保持独立。

OpenAI 对目标状态的表述非常直接：Codex 工作正在从数分钟延长到数小时甚至数天；任务应在初始会话结束后继续，用户可以在别处查看进度、提供方向、决策和审阅结果；即使笔记本合上，Agent 也应继续在客户云环境中工作。

Ona 提供的是安全、可复现、持久的执行环境，重点控制运行位置、可访问资源、凭据范围、活动日志和审阅交接。客户控制执行环境，OpenAI 提供 intelligence 与 orchestration。

这是 OpenAI 对 persistent environment 的正式产品方向，不等于收购已完成，也不等于所有 Codex 用户已经获得该能力。
