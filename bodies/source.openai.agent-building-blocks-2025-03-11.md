# New tools for building agents

OpenAI 于 2025-03-11 正式发布 Responses API、内置 web/file/computer-use tools、Agents SDK 与 tracing，并把 agent 定义为“代表用户独立完成任务的系统”。Agents SDK 面向单 Agent 与多 Agent workflow，提供 handoff、guardrail 和 trace。

该发布确立的是构建 agentic workflow 的开发原语，不是 persistent agent 产品：它没有承诺长期身份、跨任务记忆、调度、持续环境或组织权限模型。
