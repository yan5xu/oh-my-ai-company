## 已确认事实

`ateve.ai` 将 Ateve 定位为面向 AI agents 的 Web Search API，公开 `/v1/search`、Search/Extract、Python、Node.js、Java 和 cURL 入口。文档把能力分为 API/SDK、MCP、CLI + Skills，并明确 MCP 可接入 Cursor、Claude Code 等兼容环境；OpenAI tool-calling 页面说明可把 Ateve Search 暴露为 agent tool。

LinkedIn 公司页自述 ATEVE 为 San Francisco 的 AI-native infrastructure company，目标是以实时搜索、live entity data 和原始来源 verification 连接 LLM/AI agents 与现实世界；页面标注 11-50 人。该人数和定位由公司自行维护，不是独立规模证明。

Luma 官方议程与 Eileen Weng 的公开档案共同确认：Eileen Weng 是 ATEVE Founder & CEO。她的档案同时写明 `Co-founder of Bocha`。中文公开报道进一步把她识别为博查联合创始人/CTO、哥伦比亚大学计算机相关硕士背景；这能支持人物连续性，不能证明 Ateve 与 Bocha 的公司关系。

## 品牌与法律实体边界

Bocha 的官方开放平台同样提供面向 AI 的 Web Search API 和 Reranker API，产品类别与 Ateve 高度相邻。但截至本轮：

- Ateve 官网没有公开法律公司全称、注册地或公司编号；
- footer 的 About、Trust Center、Security、Twitter、LinkedIn、GitHub 均为 disabled links；
- `/privacy` 与 `/terms` 返回 404；
- 没有找到 Ateve 或 Bocha 官方公告，说明 Ateve 是 Bocha 海外品牌、子公司、spinout，还是 Eileen Weng 的独立新公司。

因此只能确认**人物与产品连续性**，不能把 Ateve 与 Bocha 合并为同一法律实体，也不能把 Bocha 的客户、融资、索引规模或产品历史继承给 Ateve。
