# Airwallex 现场简报来源

- 官方 Series H 公告：https://www.airwallex.com/global/newsroom/airwallex-secures-320-million-in-series-h-funding-valuation-hits-11-billion
- 核验时间：2026-08-03
- 证据等级：S1（公司官方；经营数字为公司自报）

Airwallex 是全球支付与金融平台，产品覆盖多币种账户、跨境转账、卡、费用管理、收单、账单、平台 API 和嵌入式金融。

2026-06-25 公司宣布 3.2 亿美元 Series H、估值 110 亿美元、累计融资 18 亿美元。公司同时自报：2026-03 年化收入 13 亿美元、年化交易量 2,870 亿美元、服务 676,000+ businesses、85+ licenses、2,300+ 员工和 27 个办公室。

公司还宣布 T:0 autonomous finance platform（当时 private beta）和 Airi agentic wallet。Airi 规划包含 delegated agent payments、spend limits、permission controls 和 multi-currency balances；未来计划不能写成当前已全面可用。
