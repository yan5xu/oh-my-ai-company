# MiraDay Docs — product and agent team

采集时间：2026-08-03。主要页面：

- https://docs.mira.day/en/docs/meet-mira/what-is-mira
- https://docs.mira.day/en/docs/meet-mira/agent-teams
- https://docs.mira.day/en/docs/get-started/quick-start
- https://docs.mira.day/en/docs/get-started/export-and-share
- https://docs.mira.day/en/docs/tools-and-teamwork/skills
- https://docs.mira.day/en/docs/tools-and-teamwork/contacts

文档将 MiraDay 定义为专业/领导力招聘的人才智能平台。用户在 Channel 中描述职位，Agent 团队生成计划、寻访和候选人池；默认交付 40 人，可要求其他数量。候选人卡片显示 Good/Partial/Low Match、逐项证据、最近经历、教育和链接；邮箱/电话按需消耗 Credits。

Channel 内保存完整对话上下文，但新 Channel 从空上下文开始，尚无跨 Channel 的偏好记忆。结果可导出 Excel/CSV，可用链接分享给没有账户的接收者。

Skills 分官方与个人两类，可用对话创建或导入 `.md`、`.skill`、`.zip`；支持编辑、导出、删除、启用/禁用，但没有内置团队分享，需要手工导入导出。

Contacts 支持 PDF、Word、Excel、CSV、HTML 导入及 enrich。解析、候选数量和速度均为厂商文档自述，未做登录后实测。
