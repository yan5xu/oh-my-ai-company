# CodexLoom

> 本对象只保存截至 2026-07-30、公开 `main=218dc4bf5c95b4c514475e471bc1acf3c0e31ab7` 可确认的产品基线。它不是完整公司调研，也不使用本地 dirty worktree。

CodexLoom 是一个面向长期 Codex Agent 的工作环境。它不重新实现 Agent Runtime，也不复制 Thread 历史；Codex 继续提供 Runtime、Thread 与 Desktop/Mobile 等入口，CodexLoom 在其上增加稳定 Agent 身份、Profile、长期 Domain 责任、组织关系、Agent 间通信、Human 治理和外部 Conversation 边界。[[source.codexloom.github-main-218dc4b]]

当前核心对象是由一个高级个人 Owner 长期维护的 Codex Domain Agent Team，而不是通用企业多租户系统、项目管理器或多 runtime 编排层。产品本地优先、自托管，并可通过飞书、Slack、Parall 的受治理 Interface Agent / Conversation Membership 让外部协作者在既有会话中使用成熟能力。[[source.codexloom.website-2026-07-30]] [[source.codexloom.owner-guide-218dc4b]] [[source.codexloom.conversation-membership-218dc4b]]

与 Raft 的有界比较见 [[note.codexloom-vs-raft-2026-07-30]]。
