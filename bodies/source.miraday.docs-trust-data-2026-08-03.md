# MiraDay Docs — matching, sources and trust

采集时间：2026-08-03。主要页面：

文档称 MRE 会对职位条件做推理检索，并逐项标记 met / uncertain / not met，提供证据而非单一数值分。MiraDay 自述 MRE 在 2026-07 的 BRIGHT 榜单中 overall 第一，并引用四篇论文；本轮只独立确认了 PJB 与 CRE-T1 论文存在，未独立重跑 BRIGHT 或验证 MRE 线上模型与论文模型完全一致。

候选人来源包括 LinkedIn、X、GitHub、Hugging Face、论文与公司资料，第三方供应商 Exa、Apollo、RocketReach，自有索引、用户上传资料和浏览器扩展。`4.5B public records` 是厂商自述，未获得独立审计。

文档明确产品不会决定是否录用、不会发明候选人或事实、不按受保护属性排名，也不会默认抓取联系方式。最终决定仍由人负责。
