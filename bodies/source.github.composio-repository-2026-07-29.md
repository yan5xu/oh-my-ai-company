# Composio GitHub repository snapshot

Collected at: 2026-07-29.

URL: <https://github.com/ComposioHQ/composio>

## Observed facts

- Public monorepo, MIT license.
- Contains TypeScript and Python SDKs, CLI, documentation, provider/framework
  adapters, examples, and integration packages.
- README positions the project around toolkits, managed authentication,
  per-user sessions, triggers, tool search, and sandboxed execution.
- Visible repository counters at collection were approximately 29.4k stars
  and 4.7k forks.
- Recent commits and open issues/PRs show active development.

## Boundary

Stars and forks measure repository attention, not active customers, paid
adoption, integration quality, security, or production reliability. The MIT
repository does not by itself prove that every hosted control-plane component
is open source or self-hostable.
