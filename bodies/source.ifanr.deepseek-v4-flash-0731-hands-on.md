# 爱范儿 DeepSeek V4 Flash 0731 五项实测

爱范儿在发布首日使用 API 连续完成五项任务：320 条新闻分析并生成交互 HTML、单文件打砖块游戏、RK4 三体模拟器、科幻仪表盘、GitHub API 周报脚本与网页。文章声明没有追问或人工干预，五项均完成；共 393 次 API 请求、约 3422 万 tokens、费用约人民币 2.85 元。

这是一组有明确任务和成本的第三方 hands-on，支持低成本、高吞吐和多类 coding/agent 任务可用性；但只有五项任务，没有公开完整可复现 harness，也不能代表长期稳定性、复杂仓库修复或全面模型排名。
