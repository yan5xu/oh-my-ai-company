# Introducing workspace agents in ChatGPT

OpenAI 于 2026-04-22 在 ChatGPT 中推出 Workspace agents research preview，面向 Business、Enterprise、Edu 与 Teachers。官方描述这些 Codex-powered shared agents 可处理复杂任务和 long-running workflows，在云端运行，用户离线后仍可继续；每个 Agent 有专属 workspace，可访问文件、代码、工具并具备 memory，可在 ChatGPT 与 Slack 中使用，也可按计划执行。

治理能力包括工具与数据范围、动作权限、敏感动作审批、运行/使用 analytics、Enterprise/Edu RBAC，以及通过 Compliance API 查看配置、更新和运行轨迹并暂停 Agent。

证据边界：这是 research preview，不是面向所有 ChatGPT 用户的通用长期员工。页面同时把新 triggers、增强仪表盘、更多跨工具动作和 Codex app support 列为后续能力，不能倒写为 2026-04-22 已全部上线。
