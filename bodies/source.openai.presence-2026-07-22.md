# Introducing OpenAI Presence

OpenAI 于 2026-07-22 发布 Presence，定位为企业部署语音与聊天 Agent 的 managed product。它组合 policy、guardrail、approved action、simulation、eval、human handoff 与 Codex-driven improvement loop；生产会话暴露缺口后，Codex 提议更新，团队测试并批准受控发布。

Presence 证明 OpenAI 已把“上线后持续改进且仍由企业控制”做成企业产品流程，但它从具体任务开始，目前由 OpenAI FDE 与精选集成商交付，仅向符合条件企业有限公开，不是 self-service，也不是通用 chief-of-staff Agent。
