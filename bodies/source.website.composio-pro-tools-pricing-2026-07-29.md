# Composio Pro Tools pricing documentation snapshot

Collected at：2026-07-29（Asia/Shanghai）

URL：<https://docs.composio.dev/toolkits/pro-tools>

## 页面可见事实

官方将搜索 API、Code Sandbox、网页抓取与结构化提取、AI/ML 推理、文档/OCR 和重型
计算等额外成本能力称为 Pro Tools。

现行页面表格：

- Free：20K Standard Tool Calls、1K Pro Tool Calls。
- Ridiculously Cheap：200K Standard、5K Pro；Standard 超额
  $0.299/1K，Pro 超额 $0.897/1K。
- Serious Business：2M Standard、50K Pro；Standard 超额
  $0.249/1K，Pro 超额 $0.747/1K。
- Enterprise：Flexible。

官方概括 Pro Tool Call 大约是 Standard Tool Call 的三倍，并为 Pro Tools 设置更低的
Rate Limit。

## 证据边界

该文档反映 2026-07-29 可见的现行 Pro Tools 价格。updated pricing 已改用 Premium
Tools Credit 和 variable surcharge 表达未来计费，因此两者不能直接合并为一套长期规则。
