# MiraDay Features

采集时间：2026-08-03。

功能页把 Channel 描述为人和 Agent 共享的工作单元，AgentOS 协调任务、角色、Skills、工具、活动、分析和人工反馈。已公开的控制原语包括自动、自动但需审核、手动三类自治方式；步骤级暂停、分析和回退；触达前审批；动作日志和证据来源。

产品能力包括自然语言职位理解、跨源候选人检索、角色化排序、联系人记录、人才池、证据和浏览器扩展。页面图示中出现 Ashby、Greenhouse、Workday 等 ATS，但正文明确直接 ATS 支持仍在 coming soon 阶段，不能把架构图当作已交付集成清单。
